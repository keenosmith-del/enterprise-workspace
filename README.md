# SQL Data Management Platform

## Overview

This project is a business data management platform built with React, Express, PostgreSQL, and Prisma ORM to demonstrate relational database engineering, SQL-driven application development, and modern full-stack architecture.

The application enables users to manage multiple interconnected datasets through reusable workspace components, relational database modelling, and dynamic CRUD operations. It focuses on building a structured data management system that mirrors real-world business applications while demonstrating clean frontend architecture, asynchronous client-server communication, and maintainable backend design.
